# Sanaap Backend Challenge – Algorithm Tasks

این مخزن شامل **دو تسک الگوریتمی** است که با هدف ارزیابی توانایی حل مسئله، تحلیل الگوریتم و پیاده‌سازی بهینه طراحی شده‌اند.

---

## 🧩 Task 1: Longest Substring Without Repeating Characters

### شرح مسئله
یک رشته ورودی دریافت می‌کنیم. هدف، پیدا کردن **طول بزرگ‌ترین زیررشته‌ای** است که در آن **هیچ کاراکتری تکرار نشده باشد**.

### مثال
```text
Input:  ABCABCFKAB
Output: 5
```

**توضیح:**
- زیررشته `ABCFK` دارای طول 5 است
- هیچ کاراکتری در آن تکرار نشده

### رویکرد حل
- استفاده از تکنیک **Sliding Window**
- نگهداری مجموعه‌ای از کاراکترهای مشاهده‌شده
- جابه‌جایی پنجره در صورت مشاهده تکرار

### پیچیدگی
- Time Complexity: `O(n)`
- Space Complexity: `O(n)`

## 🧩 Task 2: Check Four Consecutive 1s (Circular Binary)

### شرح مسئله
یک رشته باینری داده می‌شود. بررسی کنید آیا **۴ عدد 1 پشت سر هم** وجود دارد یا خیر.

⚠️ نکته: رشته به‌صورت **چرخشی (Circular)** در نظر گرفته می‌شود؛ یعنی انتهای رشته به ابتدای آن متصل است.

### مثال
```text
Input:  1010111
Output: True
```

**توضیح:**
- سه `1` در انتهای رشته و یک `1` در ابتدای آن وجود دارد
- با در نظر گرفتن چرخش، توالی `1111` تشکیل می‌شود

### رویکرد حل
- الحاق رشته به خودش (`s + s`)
- جستجوی زیررشته `1111`
- محدود کردن طول بررسی به اندازه رشته اصلی

### پیچیدگی
- Time Complexity: `O(n)`
- Space Complexity: `O(n)`
